# MHXX 頑シミュ (Android)

モンスターハンターダブルクロス (MHXX) 用スキルシミュレーターのAndroid移植版です。

元ツール「頑張って作ったモンハンシミュレータ for MHXX ver.0.9」(Java Swing) のデータとコア検索ロジックを Kotlin で再実装しています。

## 機能一覧

| 機能 | 説明 |
|------|------|
| **スキル検索** | カテゴリ別スキル選択、組み合わせ探索 |
| **除外装備 / 固定装備** | 部位ごとに装備を固定・除外。ON/OFF切替可 |
| **護石登録** | 所持護石を登録して検索に反映 |
| **仮想護石検索** | 結果0件時に「持っていれば発動する」護石を提示 |
| **マイセット保存** | 検索結果を長押しで保存。永続化対応 |
| **追加スキル検索** | 結果を長押しで「あとNptで発動できるスキル」を表示 |
| **まとめ装備検索** | 胴系統倍加・同一発動スキル構成をグループ化 |
| 胴系統倍加 | 対応済み |
| 複合スキル | FUKUGO.txt 67種対応 |

## 操作方法

1. **スキルタブ** — カテゴリからスキルを選択 → 検索
2. **結果タブ** — 結果を長押しでメニュー表示
   - マイセットに追加
   - 追加スキル検索
   - この装備を除外
   - 展開する（まとめ時）
3. **除外/固定タブ** — 装備名を入力して固定 or 除外
4. **護石タブ** — 系統・ポイント・スロットを入力して登録
5. **マイセットタブ** — 保存済みセットの確認・削除

## ビルド方法

### ローカル

```bash
./gradlew assembleDebug
# APK: app/build/outputs/apk/debug/app-debug.apk
```

### GitHub Actions

`main` / `master` への push で自動ビルド。  
Actions → Artifacts から APK をダウンロード。

## プロジェクト構成

```
mhxx-gansimu/
├── core/          # 純Kotlin検索エンジン (Android非依存)
│   └── engine/    # SearchEngine, SkillEngine
│   └── model/     # 全データモデル
│   └── parser/    # CSVパーサー
├── app/           # Android UI (5タブ)
│   └── assets/data/  # MHXX CSV (UTF-8)
└── .github/workflows/ # APK自動ビルド
```

## 注意事項

- 元ツールの「スキル加点+2」「護石系統倍加」は原作未対応のため本移植でも同様
- 仮想護石は最低限必要なポイントの組み合わせを提示（ゲーム内出現保証ではない）
- データは元ツールCSV (CP932→UTF-8変換済)
